# 離乳食管理アプリ 🍼

赤ちゃんが食べた離乳食を記録するための、シンプルなブラウザアプリです。
食材・日付・反応（食べられた／様子見／合わなかった）・メモを残せます。

ビルドツールやサーバーは不要で、`index.html` を開くだけで動きます。
データはブラウザの localStorage に保存されます。

## 主な機能

- 食材ごとの記録の追加・削除
- 反応の3段階記録（食べられた / 様子見 / 合わなかった）
- 任意のメモ
- 反応ごとの件数サマリー
- 日付の新しい順での一覧表示

## 使い方

1. このリポジトリをクローン、またはダウンロードします。
2. `index.html` をブラウザで開きます。

それだけです。インストールは不要です。

## 開発

ロジック部分（`src/logic.js`）は UI から切り離してあり、テストできます。
テストは Node.js（v18 以降）の標準テストランナーを使うため、追加の依存はありません。

```bash
npm test
```

### ディレクトリ構成

```
.
├── index.html        # 画面
├── styles.css        # スタイル
├── src/
│   ├── logic.js      # 純粋ロジック（テスト対象）
│   └── app.js        # 画面とのつなぎ込み・localStorage
└── test/
    └── logic.test.js # ロジックのテスト
```
