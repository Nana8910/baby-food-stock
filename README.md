# りにゅうしょく ストック 🍼

赤ちゃんの離乳食の**作り置きストックを管理する**ブラウザアプリです。
ゆでた野菜の在庫（個数・冷蔵/冷凍・作った日）を記録し、鮮度の目安を表示。あげた分は古いストックから自動で減らします。

ビルドツールやサーバーは不要で、`index.html` を開くだけで動きます。
データはブラウザの localStorage に保存されます。

## 主な機能

- 🧺 **食材タブ**: 冷蔵庫の生野菜を登録（数量・単位・保存場所・使い切りたい日）。残り日数バッジを表示し、ここから「ストックを作る」と使った分だけ食材が自動で減ります
- 🥕 **在庫タブ**: 「つくる」でゆでた野菜・お肉・ごはんを登録（個数・冷蔵/冷凍・作った日）。野菜 / タンパク質 / ごはんの**カテゴリ別**に表示
- 🟢 **鮮度バッジ**: つくりたて / 早めに / 期限すぎ を作った日から自動判定（冷蔵は約2日、冷凍は約1週間）
- 📊 **サマリー**: やさいの種類数・ストック合計・期限すぎの数
- 📋 **おすすめ献立**: いまの在庫から「ごはん1＋タンパク質1＋野菜3」を組み合わせて数日分を自動提案（1日の回数を1〜3で切替）。毎食なるべく違う組み合わせにします
- 🗓️ **計画タブ**: 「あげる」画面と同じ感覚で、日付×時間帯ごとに**何を何個あげるか**を計画・編集。計画に対して在庫が**いつまで足りるか**を表示し、**不足分を作り置き予定として自動逆算**（手動追加・調整も可）。作り置きの材料で食材が無いものは**買い物予定**に。各食事の「あげた」で記録＆在庫消費に直結（日ごとの確定つき）
- 🥄 **あげるタブ**: 朝/昼/晩・時刻つきで1食ごとに記録。在庫から**古い分から自動で消費（先入れ先出し）**。**在庫にないもの**（バナナ等）も直接記録でき、**ごはんのふりかけ**も添えられます
- ⏰ **期限の直接入力**: ストックに期限を入れると「あと◯日／期限すぎ◯日」をその日付で表示（空欄なら従来の自動判定）
- ✏️ **きろくの編集**: あとから品目・数量・時間帯・ふりかけを修正。数量の差分だけ在庫を自動調整
- ↩️ **取り消し**: あげた記録を戻すと在庫も復元

> ⚠️ 鮮度・おすすめはあくまで「作った日 / 在庫」からの目安です。最終的にあげる・あげないの判断はご自身でお願いします。

## 使い方

1. このリポジトリをクローン、またはダウンロードします。
2. `index.html` をブラウザで開きます。

それだけです。インストールは不要です。

## 開発

計算ロジック（`src/logic.js`）は UI から切り離してあり、テストできます。
テストは Node.js（v18 以降）の標準テストランナーを使うため、追加の依存はありません。

```bash
npm test
```

### ディレクトリ構成

```
.
├── index.html        # 画面（構造のみ）
├── styles.css        # スタイル
├── src/
│   ├── logic.js      # 純粋ロジック（鮮度・FIFO・カテゴリ・おすすめ献立など、テスト対象）
│   └── app.js        # 画面とのつなぎ込み・localStorage
└── test/
    └── logic.test.js # ロジックのテスト
```
